# The sidebar of the docs site: its order, its groups and the labels of its pages (docs/contribute/docs-site.md).
#
#   == Group title | Group lead (optional)   starts a sidebar group. The lead becomes the group index description.
#   ==                                          ends the group: the pages below it are top-level pages again.
#   path | Sidebar label | Description (optional)   a page; the description is used when the page has no page-description.
#   a path with a *                             every file that matches, sorted (docs/cli/*.md); the label of a command
#                                               page is its command without the program name. README.md files never match.
#
# A page of site/pages/ (the plan builder) is staged at the top of the site (site/pages/plan.md is /plan/), not in the docs
# tree; listing it here puts it in the index of its group.
#
# stage.sh fails on a docs/**/*.md file that is not listed here (docs/cli/README.md excepted), and on a listed file that does
# not exist, so a new, renamed or removed page always shows up in this file. STAGE_LENIENT=1 turns both errors into warnings.
# The landing page (README.md) is not listed: it is the content of the home page of the site.
