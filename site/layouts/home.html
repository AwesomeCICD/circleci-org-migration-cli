Pick your migration

Each runbook is one page of steps with copy-paste commands. Not sure which one you need? Choose a migration.

You are movingRunbook
A GitHub OAuth org to a standalone GitHub App orgOAuth to GitHub App
A GitHub or Bitbucket OAuth org to another OAuth orgOAuth to OAuth
A GitHub App or standalone org to another standalone orgApp to App

Your first steps

  1. Install circleci-migrate and verify the signature of the release.
  2. Open the plan builder, enter your source and destination orgs, and get your commands in order. Or follow a runbook above.
  3. Run export and a dry run of sync first. Nothing changes in either org until you pass --apply.

What moves by itself, what needs a step and what you do by hand is in What moves.
